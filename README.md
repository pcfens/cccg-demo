Higher Education's Cloud Computing Community Group
==================================================

The Cloud Computing Community Group (CCCG) provides participants with the opportunity to learn about and discuss the challenges and opportunities associated with the adoption of cloud computing in colleges, universities, and similar institutions. Examples of discussion topics include cloud management practices, compliance and legal issues, data privacy and security considerations, cloud identity and access management, cloud service integration (cloud to cloud and cloud to on-premise), research computing, skills and staffing implications, vendor relationship management, and cloud use cases to enable institutional agility, efficiency, and innovation.

The CCCG holds monthly meetings via Zoom on the 4th Wednesday of the month at 9AM PT / 12PM ET
